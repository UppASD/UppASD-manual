UppASD manual
=============

The `UppASD <https://github.com/UppASD/UppASD>`_ software is developed to perform atomistic spin dynamics simulations of magnetic materials. It further has features like Monte Carlo simulations and linear spin wave theory calculations for magnetic excitations. This manual provides comprehensive documentation on how to use the software, including input file formats, simulation methods, observable measurements, and more.
